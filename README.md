# unep-inorganic-chemical-space
UNEP inorganic chemical space — consultation interface

This repository contains a searchable HTML interface for exploring 2,128 substances identified through chemical curation of the UNEP chemicals-in-plastics compilation.

Substances can be searched by name, CAS number and curated identifier, and filtered by elemental composition and chemical category.

The selection is based on chemical composition. Inclusion does not establish technological function, occurrence in finished plastics or environmental risk.

The interface accompanies the manuscript Making the inorganic chemical space of plastics accessible: systematic curation of the UNEP chemicals-in-plastics compilation.

The interface can be opened directly through GitHub Pages.
